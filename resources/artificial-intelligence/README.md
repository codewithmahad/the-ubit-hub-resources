## A way to use the notes

For an agent question, identify what the agent can observe, what it can do, and how success is measured. For a search question, write the initial state, possible actions, and goal before tracing the search. Try that yourself first, then compare your reasoning with the worked assignment.

This is a partial collection. A few scans include a boundary page from the next chapter, so use the handwritten headings to find your place. Compare the topics and questions with your current classes rather than treating these files as the whole syllabus.
