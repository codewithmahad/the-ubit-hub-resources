# Find your course notes

Choose a course, then compare the sets listed under each teacher. Check the program, term, topics, and programming language when recorded. A shared course name does not always mean the same outline.

- **[Communication & Presentation Skills](./communication-and-presentation-skills/)**: Sir Fazal Ur Rehman’s course; typed notes on communication, writing, and presentations.
- **[Data Structures & Algorithms](./data-structures-and-algorithms/)**: The DSA Blueprint, a general roadmap with practice links and a printable tracker. Teacher-specific lecture notes have not been added yet.
- **[Digital Logic Design](./digital-logic-design/)**: Sir Bari’s revision guide, two handwritten sets, MCQ practice, and a logic-gates sheet. Some teacher details are still missing.
- **[Linear Algebra](./linear-algebra/)**: semester notes from Miss Fozia Hanif’s course.
- **[Software Requirement Engineering](./software-requirement-engineering/)**: Sir Hussain Saleem’s SE453 course; outline, typed notes, handwritten notes, and revision summaries.
- **[Urdu](./urdu/)**: Sir Dr M Sajid Khan’s course; Mahad’s notes on poetry, prose, and literary genres.

Open a PDF to read it or download it for later. Each set has a short guide with its context and credit. `general/` holds independent study resources; `teacher-not-recorded/` holds material whose teacher still needs to be confirmed.

Missing the set you need? [Request notes](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=notes-request.yml). Made your own? [Share them with the next batch](../CONTRIBUTING.md).
