# Subject directory

Choose a subject to open its guide. Each guide explains the files available and recommends where to start.

- **[Software Requirement Engineering](./software-requirement-engineering/)** — course outline, typed and handwritten notes, and reference chapters.
- **[Digital Logic Design](./digital-logic-design/)** — exam guide, notes, MCQ practice, Floyd chapters, and a logic-gates reference sheet.
- **[Linear Algebra](./linear-algebra/)** — semester lecture notes from Miss Fozia Hanif’s course.
- **[Communication & Presentation Skills](./communication-and-presentation-skills/)** — course notes and Murphy/Guffey reference books.
- **[Urdu](./urdu/)** — comprehensive notes, ghazals, and selected prose.
- **[Data Structures & Algorithms](./data-structures-and-algorithms/)** — The DSA Blueprint roadmap, practice links, and printable tracker.

Open a PDF to read it in your browser or download it for later. Compare the available material with your current course outline.
