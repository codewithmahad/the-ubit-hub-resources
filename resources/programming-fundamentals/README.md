# Programming Fundamentals

**Practice sheets by Shaikh Mahad** · For students building their programming basics.

I made these sheets to practise the part that takes time: reading a problem, deciding how to approach it, and getting the logic to work. Start small. Solving a few questions yourself will help more than reading through a long list of answers.

## Where to start

New to programming? Open the [short final exam practice sheet](./practice-sheets-by-shaikh-mahad/Final_Exam_Practice.pdf) and begin with Levels 0 and 1. Those start with input, arithmetic, conditions, and loops. Leave the harder sections until those feel familiar.

Then move through arrays, strings, functions, and recursion. Work in the language you are learning, and skip any language-specific question your course has not reached. The pointers sheet is for **C++**.

## Make the practice count

Before coding, work through one example on paper. After your program works, try a case you did not use while writing it: an empty string, one array element, repeated values, or a boundary value where the question allows it. If it breaks, trace what happened. That is useful practice too.

These are question sheets, not a solved course or a promise of what will appear in an exam. You do not need a particular teacher or batch to use them. Open a PDF to read it, or download it from GitHub’s file viewer.

If a question is unclear, [send me the sheet and question number](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=resource-problem.yml). A clearer question helps everyone who tries it next.
