## Use the working, then try again

If you get stuck, compare the first step where your method differs from mine. Then close the PDF and try the question again. For an integral, check the region and limits as carefully as the integration itself.

These files contain selected worked questions, not every answer in the book. Match the question as well as its exercise number if you use another edition. A few scans overlap at exercise boundaries; follow the heading written on the page.

You can read each PDF on GitHub or download it from the file viewer. If a result or a step looks wrong, [send the exercise, question, and page number](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=resource-problem.yml). I would rather fix it than have the next student carry the same mistake forward.
