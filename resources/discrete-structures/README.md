## What is covered so far

There are three note sets here, not a full semester of notes. Chapters with solutions may not have lecture notes beside them, and a chapter filename does not mean every question is solved. Match the exercise number and question itself before using an answer, especially if your book edition differs.

For counting questions, write down what you are choosing and whether order matters before picking a formula. For relations, try a small example or draw the pairs first. If an answer still does not make sense, [ask with the PDF and page number](https://github.com/codewithmahad/the-ubit-hub-resources/issues/new?template=study-question.yml).

Read the PDFs on GitHub or download them from the file viewer. Check your own course outline if your teacher covers a different selection of topics.
